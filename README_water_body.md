# 水体数据分析工具

这个工具用于分析水体数据，包括自然和非自然水体的面积统计、不同年份的水体数量和面积变化等。

## 功能特点

- 分析水体数据，包括自然和非自然水体
- 统计不同国家的水体面积和数量
- 分析不同年份的水体数量和面积变化
- 生成可视化图表
- 导出统计结果到Excel表格

## 数据要求

输入的Excel表格需要包含以下列：
- `Type`列：包含"nature"和"non-nature"值，表示水体类型
- `country`列：表示国家名称，可能有重复值（代表同一国家的不同水体）
- `1990`-`2020`年份列：每一列代表该年份的水体面积值，空值（缺失值）不进行统计

## 使用方法

### 1. 创建示例数据

如果您没有实际的水体数据，可以使用以下命令创建示例数据：

```bash
python water_body_cli.py create-sample
```

这将在`data/sample`目录下创建一个名为`water_body_data.xlsx`的示例数据文件。

### 2. 分析水体数据

使用以下命令分析水体数据：

```bash
python water_body_cli.py analyze <Excel文件路径> [-o <输出目录>]
```

例如：

```bash
python water_body_cli.py analyze data/sample/water_body_data.xlsx -o results
```

这将分析指定的Excel文件，并将结果保存到指定的输出目录（默认为`output`）。

### 3. 直接使用Python脚本

您也可以直接运行水体分析脚本：

```bash
python water_body_analysis.py
```

这将启动交互式界面，提示您输入Excel文件路径。

## 输出结果

分析完成后，将在输出目录中生成以下内容：

1. **统计表格**：`water_body_statistics.xlsx`，包含以下工作表：
   - 国家统计：每个国家的水体总面积和数量
   - 类型统计_数量：自然和非自然水体的数量
   - 类型统计_面积：自然和非自然水体在不同年份的面积
   - 年份统计：每年的水体数量和总面积

2. **可视化图表**：
   - 各国水体总面积.png：展示前10个国家的水体总面积
   - 自然非自然水体数量对比.png：自然和非自然水体数量的对比
   - 自然非自然水体面积年份变化.png：自然和非自然水体面积随年份的变化
   - 各年份水体数量变化.png：不同年份的水体数量变化
   - 各年份水体总面积变化.png：不同年份的水体总面积变化

- 缺失值（NaN）不会被计入统计
